# JavaScript PowerPoint Library

The Syncfusion® JavaScript PowerPoint Library is a lightweight, high-performance, and feature-rich non-UI solution written natively in JavaScript for creating, reading, and editing Microsoft PowerPoint (`.pptx`) presentations in both Node.js and browser environments. It enables developers to seamlessly integrate robust presentation-processing functionality into their applications without relying on Microsoft PowerPoint or interop dependencies. Designed to work across JavaScript, TypeScript, Angular, React, Vue, ASP.NET Core, and ASP.NET MVC platforms, the library supports programmatic generation and manipulation of PowerPoint presentations with rich slide content, including shapes, text boxes and images, providing a complete solution for PowerPoint document creation and processing.

## Key features

The following are the key features of Syncfusion® JavaScript PowerPoint Library:

* Create PowerPoint presentations programmatically using an intuitive object model for better control and maintainability.
* Load existing .pptx files, update content, and save changes without Microsoft PowerPoint installed.
* Add and customize text boxes and images, with comprehensive support for text styling and font formatting.

## Setup

To install PowerPoint Library and its dependent packages, use the following command.

```sh
npm install @syncfusion/ej2-pptx
```
