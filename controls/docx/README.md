## JavaScript Word Library

The Syncfusion® JavaScript Word Library is a lightweight, high-performance, and feature-rich non-UI solution written natively in JavaScript for creating, reading, and editing Microsoft Word (.docx) documents in both Node.js and browser environments. It enables developers to integrate Word document-processing functionality into their applications without relying on Microsoft Word. Designed to work across JavaScript, TypeScript, Angular, React, Vue, ASP.NET Core, and ASP.NET MVC platforms, the library supports programmatic generation and manipulation of Word documents containing rich content such as formatted text, paragraphs, lists, tables, images, hyperlinks, headers, footers, sections, fields, and shapes. It also preserves unsupported document content during round-trip processing to reduce unintended data loss.

### Key features

The following are the key features of the Syncfusion® JavaScript Word Library:

- Create Word documents from scratch
- Open and modify existing DOCX documents
- Save documents as DOCX files or byte arrays
- Add and format text, paragraphs, and sections
- Create bulleted and numbered lists
- Create and customize tables
- Insert images and shapes
- Add hyperlinks, content control, and fields
- Work with headers and footers
- Configure page size, orientation, margins, and other section settings
- Preserve supported and unsupported document content during round-trip processing
- Process Word documents in Node.js and browser environments

### Setup

To install the Word Library and its dependent packages, use the following command:

```bash
npm install @syncfusion/ej2-docx
```
