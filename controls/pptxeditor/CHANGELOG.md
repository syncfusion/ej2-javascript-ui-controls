## 35.2.14 (2026-11-26)

### PPTX Editor

Introducing the new JavaScript PPTX Editor, a browser-based solution for viewing, navigating, presenting, printing, and exporting PowerPoint presentations entirely within client-side browser environments. Here are its key features:

- Open and view PowerPoint (PPTX) presentations directly in modern web browsers with high-fidelity rendering.
- Navigate slides using thumbnails, keyboard shortcuts, mouse interactions, and touch gestures, with built-in zoom support.
- Deliver smooth performance for large presentations through slide virtualization and optimized rendering.
- Present slides in full-screen slideshow mode and review speaker notes alongside slides.
- Print presentations and export presentations in PowerPoint (.pptx) format directly from the editor.
