# JavaScript Excel Library

The Syncfusion® JavaScript Excel Library is a lightweight, high-performance, and feature-rich non-UI solution written natively in JavaScript for creating, reading, and editing Microsoft Excel (`.xlsx`) workbooks in both Node.js and browser environments. It enables developers to seamlessly integrate robust spreadsheet-processing functionality into their applications without relying on Microsoft Excel. Designed to work across JavaScript, TypeScript, Angular, React, Vue, ASP.NET Core, and ASP.NET MVC platforms, the library supports programmatic generation and manipulation of Excel workbooks with rich spreadsheet content, including worksheets, formulas, charts, tables, images, shapes, hyperlinks, comments, conditional formatting, data validation, and form controls, providing a complete solution for Excel document creation and processing.

## Key features

The following are the key features of Syncfusion® JavaScript Excel Library:

* Create Excel workbooks from scratch
* Open and manipulate existing XLSX workbooks
* Create and manage worksheets
* Work with text, numbers, dates, formulas, and Boolean values
* Apply formatting, styles, and conditional formatting
* Create and customize tables
* Create and customize charts
* Insert images, shapes, and text boxes
* Use hyperlinks and comments
* Merge and unmerge cells
* Create and manage named ranges
* Apply data validation
* Protect worksheets and workbooks
* Freeze rows and columns
* Work with form controls

## Setup

To install Excel Library and its dependent packages, use the following command.

```sh
npm install @syncfusion/ej2-xlsx
```
