# Syncfusion&reg; Blazor Spinner Component

The Syncfusion&reg; [Blazor Spinner Component](https://www.syncfusion.com/blazor-components/blazor-spinner?utm_source=nuget&utm_medium=listing&utm_campaign=blazor-spinner-nuget) displays loading states for long-running operations with lightweight circular progress indicators. Ideal for enhancing user experience when task progress information is unavailable.

## Key Features

* **Circular Progress Indicators** – Animated loading spinners for visual feedback
* **Multiple Animation Styles** – Diverse spinner styles to match your design
* **Customizable Appearance** – Control size, color, and animation speed
* **Theme Support** – Bootstrap, Material, Fabric, and custom themes
* **Responsive Design** – Adapts seamlessly to all screen sizes
* **Accessibility** – ARIA-compliant for accessible applications

## Supported Platforms

* .NET 8.0 or later (Blazor Web App, Blazor Server, Blazor WebAssembly and Blazor Hybrid)
* See full requirements: [System Requirements](https://blazor.syncfusion.com/documentation/system-requirements?utm_source=nuget&utm_medium=listing&utm_campaign=blazor-spinner-nuget)

![Blazor Spinner](https://raw.githubusercontent.com/SyncfusionExamples/nuget-img/master/blazor/blazor-spinner.png)

## Installation

### .NET CLI

```bash
dotnet add package Syncfusion.Blazor.Spinner
```

### NuGet Package Manager

```powershell
Install-Package Syncfusion.Blazor.Spinner
```

## Add Stylesheet and Script References

* For **Blazor Server App / Blazor Web App**, add these to `Components/App.razor` or `App.razor`.
* For **Blazor WebAssembly App**: add these to `wwwroot/index.html`.

```html
<link href="_content/Syncfusion.Blazor.Themes/bootstrap5.css" rel="stylesheet" />
<script src="_content/Syncfusion.Blazor.Core/scripts/syncfusion-blazor.min.js" type="text/javascript"></script>
```

## Quick Start

1. Register the Syncfusion® Blazor services in `Program.cs`:

```csharp
using Syncfusion.Blazor;

builder.Services.AddSyncfusionBlazor();
```

2. Add the Blazor Spinner component in a Razor page:

```razor
<SfSpinner Visible="true"></SfSpinner>
```
