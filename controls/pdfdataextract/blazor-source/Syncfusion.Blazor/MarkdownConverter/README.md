# Syncfusion® Blazor MarkdownConverter Component
This package contains the [Blazor MarkdownConverter](https://www.syncfusion.com/blazor-components/blazor-markdown-converter) for Blazor applications.The Blazor Markdown Converter is a dedicated component designed to transform Markdown-formatted text into clean, structured, and standards-compliant HTML output.
